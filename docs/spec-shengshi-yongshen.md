## 4. Algorithm (传统旺衰 + 扶抑)

### 4.1 五行计分（简化可复现）

对四柱天干、地支藏干计分（本气权重高于中气/余气）：

| 来源 | 权重建议 |
|:---|:---|
| 天干 | 8 |
| 地支藏干本气 | 10 |
| 中气 | 5 |
| 余气 | 3 |

另加 **月令得令加成**：日主同五行或印星五行在月令旺时额外加分。

输出：`{ 金, 木, 水, 火, 土 }` 原始分与百分比。

### 4.2 日主强弱（四大要素加权）

| 要素 | 权重 | 含义 |
|:---|:---:|:---|
| 得令 | **45%**（40–50%） | 月令对日主旺衰 |
| 得地 | **30%** | 地支通根（本气/中气/余气，月日支权重更高） |
| 得势 | **20%** | 天干比劫、印星数量 |
| 得生 | **10%** | 印星是否贴身、月令印是否有力 |

综合分映射：身强 / 偏强 / 中和 / 偏弱 / 身弱。

五行力量条仅作参考展示，**不主导**身强弱结论。

### 4.3 扶抑用神

| 身势 | 喜用 | 忌神 |
|:---|:---|:---|
| 身强 / 偏强 | 克泄耗（官杀、食伤、财） | 比劫、印 |
| 身弱 / 偏弱 | 印、比劫 | 财、官杀（主忌） |
| 中和 | 食伤、印 | 官杀过旺 |

### 4.4 大运流年

- 继续 `ec.getYun(gender, 2)` + `getDaYun(8)` + `getLiuNian`
- 对表项：起运时间、顺逆、前 4 步大运干支、当年流年干支
- UI：当前大运高亮；点击大运可展开该步流年（若现为全展开，保持但更清晰）

## 6. Testing / 对表

固定至少 3 例（公历 + 性别 + 是否真太阳时关闭以便对齐）：

| 用例 | 用途 |
|:---|:---|
| 1990-05-15 12:00 男 北京 关真太阳 | 与 zydx 对四柱、大运、身势倾向 |
| 再选 1 例身强明显 | 验证喜忌方向 |
| 再选 1 例身弱明显 | 验证喜忌方向 |

身势若与 zydx 用词不完全一致，允许差一档（如偏强 vs 身强），但 **喜忌方向必须同向**。

## 7. Boundaries

**Always do**
- 规则写在 `shengshi.js`，不散落在 UI
- 结果经 `BaziEngine.compute` 统一返回
- 页面注明「学习参考，非命理咨询」

**Ask first**
- 改月令节气 sect、改计分权重到明显偏离 zydx
- 增加新依赖

**Never do**
- 调候专论、盲派、AI 长文批命（本期）
- 提交 secrets / 改 vendor `lib/lunar.js` 核心除非对表必需
