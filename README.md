# 八字排盘 · 荣恩的周易学堂

专业八字排盘静态站点。

## 功能

- 输入：性别、出生地、真太阳时、公历/农历、年月日时分
- 排盘输出：
  - **四柱**（年、月、日、时）及十神、藏干、空亡、纳音、神煞
  - **身势强弱**（得令/得地/得势/得生 + 喜用忌神）
  - **刑冲合害**（原局 + 当前大运/流年互动）
  - **大运流年**（流月/流日默认收起，面诊按需展开）
  - **命格综评**（命格利弊、十神喜忌、神煞吉凶、适宜参考）
  - **天罡称骨**
  - **批注**与本地多案例存档
- 三主题配色；分析区块可折叠（面诊默认展开身势/刑冲/大运/批注）

## 本地预览

```bash
cd bazi-paipan
npx --yes serve .
```

浏览器打开提示的地址即可。

## 部署

静态托管（Netlify / Vercel / OSS），无需构建。生产站：https://ronsbazi.netlify.app

## 技术说明

- 四柱与历法：`lunar-javascript`（节气换月）
- 身势：传统旺衰 + 扶抑
- 神煞 / 格局 / 天罡称骨：传统规则归纳，仅供文化学习参考
