# 八字排盘 · 周易大学堂

专业八字排盘静态站点，参考 [周易大学堂](https://zydx.top/) 与 [八字排盘](https://wnl.zydxt.top/index.php) 功能布局。

## 功能

- 输入：性别、公历出生年月日时分
- 万年历：节气 / 农历 / 日干支，点击选日
- 十二时辰快捷选择
- 排盘输出：
  - **四柱**（年、月、日元、时）
  - **十神**、**天干**、**地支**
  - **藏干**（含十神）
  - **空亡**、**纳音**、**神煞**
  - **格局**、**天干留意**、**地支留意**
  - **称骨算命**
- 模块悬停：颜色由浅加深（CSS transition）

## 本地预览

```bash
cd bazi-paipan
npx --yes serve .
```

浏览器打开提示的地址即可。

## 部署

将 `bazi-paipan` 整个目录上传至 Netlify / Vercel / OSS 静态托管即可，无需构建。

## 技术说明

- 四柱与历法：`lunar-javascript`（节气换月 sect=2）
- 神煞 / 格局 / 合冲 / 称骨：传统规则模块（学习参考，非命理咨询）
